Run it

npm install && npm run build
npm start                      # contract adapter on :8790
node scripts/demo-run.mjs runs/demo

curl -s localhost:8790/mcp -H "content-type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
Set PARTNER_DEVICE_BASE_URL and PARTNER_DEVICE_TOKEN to switch to the HTTP device adapter. Without them the server reports realDevices: false and never pretends otherwise.
